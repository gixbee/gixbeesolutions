PostgreSQL tables

Stores persist as businesses (type = RENTAL). Photos and inventory stay on rental_items (imageUrls, quantity) unless later split.

Key rules

  • Customer books from a verified rental store.
  • Rental items belong to a rental business/store.
  • Nearby stores are shown based on city or distance radius.
  • A slot is temporarily locked before payment to prevent double booking.
  • Minimum booking advance is required to submit the reservation.
  • Owner must confirm the rental request.
  • If owner rejects, booking advance is refunded.
  • Only one confirmed booking can hold the same inventory for the same time slot (up to listed quantity).
  • Handover requires customer/owner acknowledgement and OTP.
  • Return requires acknowledgement from both parties.
  • Security deposit is refunded after successful return, minus applicable damage or penalty charges.
  • Payment status must be separate from rental booking status.
