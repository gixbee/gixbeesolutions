Gixbee Photography Owner — downloadable HTML prototype
======================================================

This implements the owner flow from your photography mock screens / V1 spec:
  List My Business → Manage (Archana Photography) → Dashboard
  Service areas (states → districts → save)
  Services & Packages hub, package filters (Basic / Standard / Premium / Custom)
  Add Package (11-step wizard) and Add Service (8-step wizard)
  Calendar, Gallery, Booking Requests (navigable stubs)

No extra folders or images required — icons and placeholders are CSS/SVG inside the file.
